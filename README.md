# ระบบนัดจองคิวทันตกรรมออนไลน์ (Dental Appointment Booking System)
ระบบนัดจองคิวออนไลน์แบบ Responsive รองรับการใช้งานผ่านโทรศัพท์มือถือ แท็บเล็ต และคอมพิวเตอร์อย่างสมบูรณ์แบบ ภาษาไทย 100%

---

## 🌟 ฟังก์ชันหลักของระบบ

### 1. ฝั่งผู้รับบริการ (ผู้ป่วย / ประชาชน)
- **ปฏิทินเลือกวันนัดหมายอัจฉริยะ (Interactive Calendar)**:
  - แสดงสถานะวันเปิดให้บริการ (สีเขียว), วันที่คิวเต็ม (สีส้ม), และวันที่ปิดทำการ (สีเทา)
  - **ในวันที่ไม่ได้เปิดให้บริการ ผู้ป่วยจะไม่สามารถกดจองเข้ามาได้** พร้อมมีข้อความแจ้งเหตุผล เช่น วันหยุดราชการ หรือทันตาภิบาลอบรม
  - เลือกรอบเวลา (Slot) ที่ต้องการ เช่น 09:00 - 10:00, 10:00 - 11:00 เป็นต้น พร้อมแสดงจำนวนคิวที่ยังว่างแบบ Real-time
- **ฟอร์มกรอกข้อมูลการจอง**:
  - ชื่อ - นามสกุล
  - เลขประจำตัวประชาชน 13 หลัก (มีระบบตรวจสอบความถูกต้อง Checksum ตามหลักการทะเบียนราษฎร์)
  - เบอร์โทรศัพท์ (10 หลัก)
  - ปุ่มลัดเลือกบริการ/อาการยอดนิยม (ตรวจช่องปาก, ขูดหินปูน, อุดฟัน, ถอนฟัน, ปวดฟัน, เสียวฟัน ฯลฯ)
  - ช่องระบุอาการเบื้องต้นโดยละเอียด
  - ช่องระบุโรคประจำตัว / ประวัติแพ้ยา เพื่อให้ทันตาภิบาลเตรียมการล่วงหน้า
- **บัตรนัดคิวอิเล็กทรอนิกส์ (Digital Slip)**:
  - ออกรหัสคิว เช่น `DEN-202611-001` ทันทีเมื่อจองสำเร็จ พร้อมปุ่มสั่งพิมพ์บัตรนัด และปุ่มคัดลอกข้อมูลบัตรนัด
- **เมนูตรวจสอบคิวนัดหมาย (Check Queue Status)**:
  - ค้นหาได้ง่ายด้วย "เลขบัตรประชาชน" หรือ "เบอร์โทรศัพท์"
  - **แสดงข้อความและคำแนะนำที่ทันตาภิบาลตอบกลับ** พร้อมสถานะ เช่น "ยืนยันแล้ว", "ขอเลื่อนนัด", "ตรวจเสร็จสิ้น"

### 2. ฝั่งทันตาภิบาล & ผู้ดูแลระบบ (Dental Staff & Admin Portal)
- **ระบบแบ่งสิทธิ์การใช้งาน (Role-Based Access Control - RBAC)**:
  - **สิทธิ์ทันตาภิบาล (Nurse):** เข้าถึงเมนูจัดการคิวผู้ป่วย ตอบกลับและเปลี่ยนสถานะนัดหมาย ปฏิทินคิวงาน กำหนดวันเปิด-ปิดให้บริการ และสรุปสถิติคิว
  - **สิทธิ์ผู้ดูแลระบบ (Admin):** ได้รับสิทธิ์ทุกอย่างของทันตาภิบาล พร้อมเมนูพิเศษ **"👥 จัดการผู้ใช้งานระบบ"** สำหรับบริหารจัดการบุคลากร
- **ระบบจัดการผู้ใช้งานระบบ (User Management System สำหรับ Admin)**:
  - **เพิ่มผู้ใช้งานใหม่ (Add User):** สร้างบัญชีสำหรับทันตาภิบาลหรือผู้ดูแลระบบใหม่ กำหนดชื่อผู้ใช้งาน ชื่อ-สกุล สิทธิ์ ตำแหน่งงาน และรหัสผ่านเริ่มต้น
  - **รีเซ็ตรหัสผ่านกรณีผู้ใช้ลืม (Admin Password Reset):** หากเจ้าหน้าที่ลืมรหัสผ่าน Admin สามารถกดปุ่ม **"🔑 รีเซ็ตรหัส"** เพื่อกำหนดรหัสผ่านใหม่ให้เจ้าหน้าที่นำไปล็อกอินได้ทันที พร้อมปลดล็อกสถานะระงับการเข้าสู่ระบบ (Rate-limiting Lockout) ให้อัตโนมัติ
  - **ลบผู้ใช้งาน (Delete User):** ลบบัญชีผู้ใช้พร้อมซิงค์ลบออกจาก Google Cloud Firestore อัตโนมัติ โดยมีระบบป้องกันความปลอดภัย (ห้ามลบบัญชีตนเอง และห้ามลบ Admin คนสุดท้าย)
- **ระบบความปลอดภัยสูงสุดระดับมาตรฐาน (High Security Staff Authentication)**:
  - จัดเก็บรหัสผ่านด้วยการเข้ารหัส **SHA-256 มาตรฐานสากล พร้อม Salt ลับเฉพาะระบบ** (ไม่เก็บรหัสผ่านเป็นตัวอักษรธรรมดา ทั้งใน LocalStorage และ Firestore)
  - ระบบ **ป้องกัน Brute-force Attack (Rate Limiting)**: ล็อกการเข้าสู่ระบบ 60 วินาทีอัตโนมัติหากใส่รหัสผ่านผิดเกิน 5 ครั้ง
  - หน้าต่างเข้าสู่ระบบออกแบบใหม่สไตล์คลินิกมืออาชีพ ไร้ข้อมูลทดสอบหลุดรอด มีปุ่มเปิด-ปิดการแสดงรหัสผ่าน (👁️)
  - มีปุ่ม **"🔑 เปลี่ยนรหัสผ่าน"** ในแดชบอร์ด เพื่อให้เจ้าหน้าที่และผู้ดูแลระบบเปลี่ยนรหัสผ่านได้ด้วยตนเอง
  - **บัญชีเริ่มต้นของระบบ (Default Accounts)**:
    - **บัญชีทันตาภิบาล:** Username: `nurse` | Password เริ่มต้น: `1234` (ทภ. รัตนา พงษ์สวัสดิ์)
    - **บัญชีผู้ดูแลระบบ (Admin):** Username: `admin` | Password เริ่มต้น: `1234` (นายเดียร์ เบญจาวิริยะวงศ์)
- **ระบบควบคุมการจองคิวอัจฉริยะ (Booking Policy & Public Holiday Engine)**:
  - **ล็อกไม่ให้จองย้อนหลัง (Lock Past Dates)** ทุกกรณี
  - **บังคับจองล่วงหน้าอย่างน้อย 5 วันขึ้นไป ($\ge 5$ วัน)** เพื่อให้ทันตาภิบาลมีเวลาเตรียมเวชภัณฑ์และแฟ้มประวัติ
  - **ปิดการจองในวันหยุดราชการอัตโนมัติ (Automatic Thai Public Holidays)** รองรับทั้งวันหยุดประจำปี วันหยุดสำคัญทางศาสนา (พ.ศ. 2568-2570) และวันหยุดชดเชยเสาร์-อาทิตย์อัตโนมัติ
  - **เปิดรับจองเฉพาะวันที่เจ้าหน้าที่กำหนด Slot และยังมีคิวว่างเท่านั้น** โดยปฏิทินจะเลือกวันแรกที่เปิดรับจองให้อัตโนมัติ
- **ปฏิทินนัดหมายภาพรวม (Appointment Calendar Overview)**:
  - มุมมองปฏิทินรายเดือน แสดงภาพรวมจำนวนคิวนัดในแต่ละวันอย่างชัดเจน
  - ป้ายสีสถานะคิวในแต่ละวัน (🟡 รอยืนยัน, 🟢 ยืนยันแล้ว, 🔵 ขอเลื่อน, 🎉 เสร็จสิ้น)
  - แถบตารางคิวนัดหมายประจำวัน (Daily Agenda) เมื่อคลิกวันใด จะแสดงลำดับคิวและช่วงเวลาทั้งหมดในวันนั้น พร้อมปุ่มกดตอบกลับได้ทันที
- **จัดการคิวและตอบกลับผู้ป่วย (Queue Management & Reply System)**:
  - ตารางแสดงรายการคิวนัดหมายทั้งหมด กรองตามสถานะ, วันที่, หรือค้นหาด้วยชื่อ/เลขบัตร ปชช./เบอร์โทร
  - ตอบกลับและเปลี่ยนสถานะ (ยืนยันนัดหมาย / ขอเสนอเลื่อนนัด / ตรวจเสร็จสิ้น / ยกเลิกคิว)
  - แม่แบบข้อความตอบกลับสำเร็จรูป (เช่น เตือนให้นำบัตร ปชช. ตัวจริงมา, คำแนะนำก่อนขูดหินปูน, แจ้งขอเลื่อนเวลา)
  - พิมพ์ข้อความตอบกลับเฉพาะเคส เพื่อให้ผู้ป่วยเห็นทันทีเมื่อเข้ามาตรวจสอบสถานะคิว
  - ปุ่มควบคุมในหน้าต่างตอบกลับแบบ Sticky (ตรึงด้านล่าง) ใช้งานสะดวกทั้งบนมือถือและจอคอมพิวเตอร์
- **กำหนดวันและ Slot เวลาให้บริการ (Schedule Setup)**:
  - เลือกวันที่ในปฏิทินเพื่อกด **"เปิดให้บริการ"** หรือ **"ปิดทำการ (ห้ามจอง)"** พร้อมพิมพ์เหตุผล
  - จัดการรอบเวลา (Slots) เพิ่ม/ลบ ช่วงเวลา และระบุจำนวนคิวสูงสุดที่รับได้ต่อรอบ
  - ปุ่มคืนค่ารอบเวลามาตรฐาน (09:00 - 16:00 น.) สะดวก รวดเร็ว
- **สรุปสถิติคิวและส่งออกข้อมูล (Stats & Export)**:
  - สรุปจำนวนคิวทั้งหมด, รอยืนยัน, ยืนยันแล้ว, ตรวจแล้ว
  - กราฟสัดส่วนอาการและหัตถการยอดนิยม
  - ปุ่มส่งออกรายชื่อผู้ป่วยนัดหมายเป็นไฟล์ **CSV (Excel รองรับภาษาไทยสมบูรณ์แบบ)**

## 🚀 วิธีการเปิดใช้งานระบบ

### วิธีที่ 1: ดับเบิลคลิกไฟล์ `start.bat` (แนะนำ)
ดับเบิลคลิกที่ไฟล์ **`start.bat`** ในโฟลเดอร์นี้ ระบบจะ:
1. เริ่มทำงาน Web Server ขนาดเบาที่ `http://localhost:8080`
2. เปิดหน้าเว็บระบบในเบราว์เซอร์ให้อัตโนมัติที่ `http://localhost:8080`
3. เปิดให้อุปกรณ์อื่น เช่น **โทรศัพท์มือถือ** ในวง Wi-Fi เดียวกันเชื่อมต่อเข้ามาใช้งานได้ผ่าน IP ของเครื่องคอมพิวเตอร์

### วิธีที่ 2: เปิดไฟล์ `index.html` โดยตรง
สามารถดับเบิลคลิกเปิดไฟล์ **`index.html`** ด้วย Google Chrome หรือ Microsoft Edge เพื่อใช้งานได้ทันทีโดยไม่ต้องผ่านเซิร์ฟเวอร์

## 🌐 การนำขึ้นออนไลน์ผ่าน GitHub Pages & Google Cloud Firestore

ระบบได้รับการเชื่อมต่อกับ **Google Cloud Firestore (Project: `dental-khuanlang`)** เรียบร้อยแล้ว ข้อมูลการจองคิวจะซิงค์แบบ Real-time ข้ามอุปกรณ์ทันที

### ขั้นตอนนำขึ้น GitHub Pages:
1. เข้าเว็บ [github.com](https://github.com) แล้วกด **New repository** (เช่น `dental-booking`) เลือกเป็น **Public**
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น Repository
3. ไปที่เมนู **Settings > Pages**
   - ในหัวข้อ **Branch** ให้เลือก `main` โฟลเดอร์ `/ (root)` แล้วกด **Save**
4. ระบบจะสร้าง URL ออนไลน์ระดับโลกให้ทันที เช่น:
   `https://<ชื่อ-username-github>.github.io/dental-booking/`
   ประชาชนสามารถเข้าจองคิวจากที่บ้านผ่านมือถือ และเจ้าหน้าที่ทันตกรรมสามารถเปิดรับคิวได้จากทุกที่ทั่วโลกทันที!

## 📱 การใช้งานผ่านโทรศัพท์มือถือ
เมื่อเปิดเซิร์ฟเวอร์ด้วย `start.bat` หน้าต่าง Terminal จะแสดงที่อยู่ IP ในเครือข่าย เช่น:
`http://192.168.1.XX:8080`
นำลิงก์ดังกล่าวไปเปิดในเบราว์เซอร์ของโทรศัพท์มือถือที่เชื่อมต่อ Wi-Fi เดียวกันได้ทันที
